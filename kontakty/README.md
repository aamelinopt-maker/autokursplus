# Контакты автошколы «Автокурс»

Готовая статическая страница с московскими филиалами, адаптивом, мобильным меню, микроразметкой и интерактивной Яндекс.Картой.

Для публикации: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Адрес после публикации: https://aamelinopt-maker.github.io/test/

Карта и внешние ссылки требуют интернет. При недоступности карты отображается заглушка. Форма проверяет данные локально и не отправляет заявку.
